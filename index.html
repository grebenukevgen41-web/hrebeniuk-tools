Hrebeniuk Tools

Аддони для Blender з автооновленням

Завантажити ВСТАНОВИТИ.bat
  1. Закрий Blender.
  2. Запусти ВСТАНОВИТИ.bat — він сам підключить цей репозиторій і поставить аддони. Старі ручні копії приберуться (резервна копія лишається).
  3. Далі оновлення приходять самі при запуску Blender. У вкладці Hrebeniuk (N-панель) — кнопка «Оновити все».

Якщо Windows попередить про невідомий файл — «Докладніше» → «Виконати все одно». Щось пішло не так — ОНОВИТИ.bat.
