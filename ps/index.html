PS Tools для Photoshop

Панель Hrebeniuk Tools: Load Images, Replace Renders, Update Masks, маски деталей, Batch Export.

Завантажити ВСТАНОВИТИ_PS_Tools.bat
  1. Браузер може попередити, що .bat-файл небезпечний, — натисни «Зберегти» / «Keep» (це звичайний установник).
  2. Запусти завантажений ВСТАНОВИТИ_PS_Tools.bat (якщо Windows попередить — «Докладніше» → «Виконати однаково»).
  3. Коли Windows попросить дозвіл — натисни «Так» (потрібно, щоб покласти панель у папку Photoshop).
  4. Перезапусти Photoshop.
  5. Увімкни панель: угорі меню Plugins → PS Tools → постав галочку (увімкнути). Панель з'явиться збоку, на панелі швидкого доступу — її можна прикріпити, далі вона відкриватиметься сама.
Оновлення — самі: коли вийде нова версія, у панелі з'явиться жовта кнопка «Оновити до v…». Натисни її — і все. Встановлювати ще раз не треба.

Потрібен Photoshop 2022 або новіший, Windows. Без інтернету: PS_Tools.zip → розпакуй → ВСТАНОВИТИ.bat. Видалити: у тому ж архіві ВИДАЛИТИ.bat.
